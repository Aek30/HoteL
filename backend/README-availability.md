# ค้นหาห้องว่าง

GET /api/rooms/availability?check_in=2026-10-06&check_out=2026-10-08&adults=2&children=0
เปิดให้ค้นหาได้ก่อน login; การสร้างการจองในขั้นถัดไปต้อง login
วันที่จริง YYYY-MM-DD วันเข้าต้องไม่ย้อนหลังตาม Asia/Bangkok วันออกต้องหลังวันเข้า
รองรับ room_type_id, page, limit (สูงสุด 100)
ข้อมูลตอบกลับมี nights และ estimated_room_total (เฉพาะราคาห้อง ไม่มีค่าใช้จ่ายเพิ่มเติม)
ค้นหาความจุสำหรับหนึ่งห้อง ไม่ใช่จัดสรรผู้เข้าพักรวมหลายห้อง
วัน checkout ไม่รวมในคืนเข้าพัก จึงรับผู้เข้าพักถัดไปวันเดียวกันได้
รายการ confirmed/checked_in และ pending ที่ยังไม่หมดอายุจะกันห้องช่วงวันทับกัน
ไม่แสดงห้อง maintenance/inactive หรือประเภท inactive
ห้อง occupied/cleaning อาจจองล่วงหน้าได้เมื่อไม่มีการจองทับและไม่ใช่กรณีผู้พักเกินกำหนดวันนี้
ผลค้นหาไม่ใช่การล็อกห้อง ต้องตรวจซ้ำพร้อม transaction ตอนสร้างการจอง
